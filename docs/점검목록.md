# 배포 전 점검 목록

`npm test`(자동 17개 + 오류 문구 1개)로 걸러지지 않는, 사람이 직접 봐야 하는 항목만 모았다.
순서대로 하면 10~15분 걸린다. 실패한 항목은 고치기 전에 여기 한 줄로 증상을 적어 둔다.

## 준비

- 테스트용 SSH/SFTP 서버: `node .scratch/server.cjs` (127.0.0.1:2222, tester / pw)
- 실제 서버 한 대 (예: 10.0.1.111)
- 테스트용 설정 폴더로 실행: `... --user-data-dir=C:\coding\app\ssh\.scratch\ud-test`

## 1. SSH

- [ ] 저장된 세션 더블클릭 → 접속
- [ ] 처음 접속하는 서버에서 호스트 키 지문 확인 창이 뜨고, 취소하면 접속되지 않음
- [ ] 비밀번호를 한 번 틀리면 다시 묻고, 취소하면 연결이 끝남
- [ ] `vim`, `top` 실행 후 정상 종료 (화면 복구 확인)
- [ ] 한글 입력·출력, 창 크기 변경이 원격에 반영 (`stty size`)
- [ ] 드래그하면 자동 복사, Alt+드래그는 사각형 선택, 오른쪽 클릭은 붙여넣기

## 2. 자동 재접속

- [ ] 접속 중에 서버를 내리면 "N초 뒤에 다시 연결합니다 (k/5)" 안내가 뜸
- [ ] 서버를 다시 올리면 스스로 접속됨
- [ ] `연결 끊기`를 누르면 자동 재접속이 멈춤
- [ ] 비밀번호를 틀려 실패한 경우에는 자동 재접속하지 않음

## 2-1. 세션 관리

- [ ] 세션 복제(⧉) 후 이름에 "(복사)"
- [ ] 세션을 다른 그룹 머리줄로 끌어다 놓으면 그룹이 바뀜
- [ ] `⋯` 메뉴에서 `~/.ssh/config` 가져오기 → Host 블록 수만큼 생성, ProxyJump가 점프 호스트로 연결됨
- [ ] 내보내기 파일에 비밀번호가 없는지 확인
- [ ] 점프 호스트를 지정한 세션으로 접속 (점프·목적지 호스트 키를 각각 확인)

## 3. X11

- [ ] X11을 켠 세션에서 `echo $DISPLAY`가 `localhost:10.0` 형태
- [ ] `virt-manager`(또는 `xclock`) 창이 내 화면에 뜨고 마우스·키보드가 동작
- [ ] X 서버가 꺼져 있으면 VcXsrv가 자동으로 뜸

## 4. SFTP

- [ ] 목록, 폴더 이동(더블클릭), 상위 폴더, 새로고침
- [ ] 파일 업로드·다운로드 후 내용 일치
- [ ] 폴더 업로드·다운로드 (하위 폴더 포함)
- [ ] 탐색기에서 끌어다 놓기
- [ ] 전송 중 취소 → 반쯤 받은 파일이 남지 않음 (`.part` 없음)
- [ ] 같은 이름 파일 덮어쓰기 확인 창
- [ ] 없는 폴더로 이동, 권한 없는 폴더 열기 → 한국어 오류 문구
- [ ] 파일 더블클릭 → 편집기로 열림, 저장하면 "저장됨" 표시되고 원격 파일 바뀜, 닫기 누르면 임시 파일 삭제

## 5. 포트포워딩

- [ ] Local: `-L 18022:localhost:22` 후 `127.0.0.1:18022`에서 SSH 배너 확인
- [ ] Dynamic: `curl --socks5-hostname 127.0.0.1:1080 ...`
- [ ] Remote: 서버에서 `curl 127.0.0.1:<포트>`
- [ ] 이미 쓰는 포트를 지정하면 빨간 오류 문구
- [ ] 중지 또는 연결 종료 후 포트가 풀림 (`Get-NetTCPConnection -LocalPort ...`)

## 6. 로컬 터미널과 화면

- [ ] `+` 메뉴에서 PowerShell, cmd, WSL 열기
- [ ] WSL 탭에서 `claude` 실행 → 화면이 깨지지 않음
- [ ] 분할: 탭 2·4·8개에서 격자 배치, 클릭한 창으로 입력 이동
- [ ] 동시 입력: 체크한 창에만 입력, 체크 해제한 창은 그대로
- [ ] 스니펫 실행 (여러 줄 포함)
- [ ] 로그 켜기 → `문서\Skiff Logs`에 파일 생성, 제어 문자 없음

## 7. 부하와 뒷정리

- [ ] 20만 줄 출력(`yes ... | head -n 200000`)이 몇 초 안에 끝나고 앱이 멈추지 않음
- [ ] 탭 8개를 띄워도 조작이 느려지지 않음
- [ ] 앱을 닫은 뒤: 터널 포트 해제, 남은 자식 프로세스 없음
      (`Get-CimInstance Win32_Process | Where-Object { $_.ParentProcessId -eq <앱 PID> }`)

- 앱 종료 후 터널 포트 해제, 자식 프로세스 0개
